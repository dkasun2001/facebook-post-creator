# Facebook Post Creator

A dark, editorial React workspace for composing Sinhala and English Facebook posts with templates, image framing, and live export preview.

Built with Manus.

---

## Features

- Compose posts in Sinhala and English with a clean, dark editorial UI
- Ready-made post templates and layout presets
- Image framing and background options for post imagery
- Live export preview (see how the post will look when exported)
- Export post as an image or copy text for direct use on Facebook

## Getting started

### Prerequisites

- Node.js (LTS recommended, >= 16)
- npm or Yarn

### Install

```bash
# clone the repo
git clone https://github.com/dkasun2001/facebook-post-creator.git
cd facebook-post-creator

# install dependencies
npm install
# or
# yarn install
```

### Run in development

```bash
npm run dev
# or
# yarn dev
```

Open http://localhost:3000 (or the URL printed in the terminal) to view the app.

### Build for production

```bash
npm run build
npm run start
```


## Usage

- Choose a template or start from a blank canvas
- Add or frame an image from the templates or upload your own
- Switch language between Sinhala and English for text composition
- Use the live preview to verify layout and export settings
- Export as image (ready for upload) or copy the text content

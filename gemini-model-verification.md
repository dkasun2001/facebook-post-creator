# Manual Gemini Model Verification

The Gemini connection panel now presents separate Headline model and Image model fields. Each includes its default model as placeholder guidance and explains that blank fields retain the studio defaults and fallback chain.

The Headline model field accepted and retained the typed value `gemini-2.5-pro`, confirming that creators can enter an exact Gemini model ID manually before generating content.

The Image model field also accepted and retained `gemini-2.5-flash-image`. Both manual model controls are therefore available independently for the headline and image workflows.
